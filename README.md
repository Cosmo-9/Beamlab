# BeamLab

BeamLab is an educational structural analysis tool that helps students understand how beam loading produces shear force and bending moment diagrams.

## Planned first release

- Simply supported beam model
- Adjustable span, point load, point-load position, and full-span uniformly distributed load
- Support reactions calculated using static equilibrium
- Shear force diagram (SFD) and bending moment diagram (BMD)
- Step-by-step calculation explanation

## Engineering scope

BeamLab is for learning and visualization. It is not a substitute for verified structural design software or professional engineering review.

## Planned stack

Next.js, React, TypeScript, and Vercel.
